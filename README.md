Gestão Barbearia

Sistema de gestão desenvolvido em Python + Flet para barbearias e salões de beleza, com foco em praticidade, personalização e utilização em dispositivos móveis.

Sobre o projeto

O Gestão Barbearia foi desenvolvido para centralizar as principais operações de uma barbearia, como atendimentos, agenda, fila, clientes, catálogo, estoque, caixa e relatórios.

Um dos principais diferenciais do projeto é o foco em acessibilidade para dispositivos móveis. Muitos sistemas de gestão são desenvolvidos pensando principalmente em computadores e possuem interfaces genéricas, que nem sempre representam a identidade ou a realidade de cada estabelecimento.

A proposta deste projeto é oferecer uma experiência mais adaptada ao uso em celulares, permitindo que o comerciante tenha acesso às principais funções do negócio diretamente pelo dispositivo que já utiliza no dia a dia, além de possibilitar uma interface mais personalizada para cada estabelecimento.

Desenvolvimento

O projeto utiliza uma arquitetura organizada para separar interface, banco de dados, regras da aplicação e componentes reutilizáveis.

O SQLite permite o armazenamento local dos dados, possibilitando uma abordagem mais independente de conexão com a internet. O projeto também possui estrutura para integração e sincronização com serviços externos.

Aplicação Mobile

A aplicação foi desenvolvida com foco em dispositivos Android, podendo ser empacotada como APK.

A interface foi pensada para telas menores e para utilização durante a rotina do estabelecimento, priorizando navegação simples, acesso rápido às funções e uma identidade visual própria.

Objetivo

O projeto tem como objetivo aplicar conhecimentos de desenvolvimento de software na construção de uma solução real, trabalhando com interface gráfica, banco de dados, organização de código, desenvolvimento mobile, integração de serviços e controle de versão.
